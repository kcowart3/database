Lux Mori

The brief for this project wanted a website designed for public use. I took that premise and decided to create a site that allowed for a sort of focused creativity that I love: sci-fi worldbuilding. Lux Mori is framed as a space atlas: enter through a starfield, move at Milky Way scale, then drop into a solar system you can explore—each layer is built to feel vast before it snaps to something clickable. Should the user choose to, they can create their own system from scratch and add to the greater world.

The clip runs through that sequence so you can see how scale, motion, and UI hand-offs were handled in the shipped build. Feel free to take a look at the current build below.
