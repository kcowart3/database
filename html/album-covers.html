Album cover series

For this project I got to craft three different album covers for the same artist under the same title. Each idea pushes one of three axes: type, pattern, or color.

Type emphasis

Title and supporting type carry the front: hierarchy, tracking, and negative space do most of the storytelling while imagery stays minimal.

Pattern emphasis

Repeating graphic texture leads the composition; typography locks in as a secondary band so the wrap still feels like music packaging.

Color emphasis

Gradient and hue shifts set the mood; forms simplify so the color story can run edge-to-edge without fighting the spine or barcode zone.
